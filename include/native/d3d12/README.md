Direct3D 12 headers for the native build, generated by Wine 11.20's widl from
Wine's `include/d3d12.idl`, `d3d12sdklayers.idl` and `d3d12shader.idl`
(LGPL 2.1 or later, as Wine). The mingw-directx-headers in
`include/native/directx` predate `ID3D12Device2` and `ID3D12Fence1`, which
`src/d3d12` uses; these come first on the include path.

Native builds define `WIDL_EXPLICIT_AGGREGATE_RETURNS`, so methods that return
a structure take a pointer to it and return that pointer, as Windows' COM ABI
does and as embedders that call through the vtable expect.
